# Iletisim-ve-Sunum-Teknikleri
Bu proje, İletişim ve Sunum Teknikleri dersi kapsamında hazırlanmıştır.
Amaç, C dili kullanarak Türkçe karakterlerin doğru şekilde ekrana yazdırılmasını göstermektir.
C programlama dilinde yazılan bazı uygulamalarda Türkçe karakterler hatalı görüntülenebilmektedir.
Bu proje, uygun karakter kodlaması (UTF-8) kullanılarak Türkçe karakterlerin sorunsuz şekilde çıktılanmasını göstermektedir.
